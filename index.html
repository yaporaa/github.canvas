About this canvas

Pixels and chat travel directly between browsers over peer-to-peer links. A lightweight signaling room is used only to discover visitors and set up those links. Direct connections form a relay ring to avoid a full-mesh connection explosion. This browser saves its own copy; if every visitor closes the site, there is no always-on machine holding a global copy. There is no report button or content moderation.

GitHub.global is an independent fan-made canvas concept and is not affiliated with GitHub, Inc.
